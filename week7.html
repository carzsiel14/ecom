What are UI, UX, and CRO?

UI

User Interface: The visual layout—buttons, menus, typography, and grids. This is how we visually present our Week 5 Database Schemas to the user.

UX

User Experience: The psychological journey. Is it intuitive to navigate from a product page to checkout based on the logic we defined in Week 4?

CRO

Conversion Rate Optimization: Applying data-driven design principles to ensure the maximum percentage of site visitors actually complete a purchase.

A brilliant backend is useless if the UI/UX introduces friction that prevents users from checking out.

How does our Week 5 ERD dictate our UI design today?

Week 5: Database Schema

In Week 5, we structured our relational database to track specific product attributes. A typical products table includes:

  • product_name VARCHAR
  • price DECIMAL
  • stock_quantity INT
  • product_variations JSON/FK
    mapping sizes/colors

Week 7: UI Requirements

The UI must fetch and display these exact fields elegantly to the customer:

  • Prominent Title & Price

    Clear formatting for immediate recognition.

  • Dynamic Dropdowns

    Color/Size selectors tied to variation data.

  • Scarcity Triggers

    e.g., "Only 2 left in stock!" (driven by stock_quantity).

Optimizing the Landing Page

Visual Hierarchy drives Action

The product landing page is where conversions are born. Based on our requirements analysis, we must prioritize clarity.

  • Use high-quality product imagery as the primary focal point.

  • Ensure the "Add to Cart" Call-to-Action (CTA) is the most vibrant element on the page.

  • Minimize clutter—only show data fields (specs, reviews) that aid the buying decision.

Recall Week 3: Mobile Architecture

Designing for the Thumbs

In Week 3, we analyzed Mobile Commerce vs. Desktop Infrastructure. Today, over 60% of e-commerce traffic is mobile. Your UI must adapt.

Tap Targets

Buttons must be at least 44x44 pixels to prevent user frustration.

Sticky Elements

Keep the "Add to Cart" button anchored to the bottom of the screen while scrolling.

Speed

Mobile networks vary. Optimize image assets so the UI doesn't block the backend data fetching.

The Shopping Cart Experience

Transitioning the user from browsing to the checkout phase requires seamless visibility and state management.

Cart Visibility & Previewing Week 9

Never Let Them Forget

A hidden cart leads to abandoned carts. UX principles dictate that the cart state should always be visible.

Dynamic Cart Icon

Use a dynamic cart icon in the navigation bar showing real-time item counts.

Slide-out Drawer

Implement a "drawer" cart to let users review items without leaving the product page.

Preview of Week 9: Session Management

The UI we design today will soon be powered by the backend Session Management we configure in Week 9 to ensure carts persist even if the user closes the tab.

Minimizing Checkout Friction

Guest Checkout

Forcing account creation is the #1 cause of cart abandonment.

Always provide a friction-less "Guest Checkout" option, requesting only essential delivery data.

Form Optimization

Connect to Wk 10: Local Fulfillment If offering Cash on Delivery (COD), hide unnecessary credit card fields to speed up the process.

Autocomplete addresses where possible.

Trust & Speed

Preview Wk 13: Security Display security badges prominently.

Ensure the final submit button gives immediate visual feedback (loading spinners) to prevent double-clicks.
